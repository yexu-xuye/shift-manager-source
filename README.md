# 排班管理系统

电脑部排班与值班管理工具，支持日常排班、周末值班和 Microsoft AD 域员工同步。

## 功能

- **排班管理**：员工/组别管理、轮换规则配置（多人 / 子组 / 单人）、周排班生成、快照保存与图片导出
- **值班管理**：值班小组与成员管理、轮换顺序配置、周末值班表生成、轮休设置、快照
- **AD 域同步**：连接测试、差异预览、选择性导入、忽略列表、同步日志

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | FastAPI + SQLAlchemy 2 + SQLite（WAL）+ ldap3 + pypinyin |
| 前端 | React 18 + TypeScript + MUI 5 + TailwindCSS + Vite |

## 环境要求

- Windows 10/11
- Python 3.10+
- Node.js 18+（仅构建前端时需要）

## 快速启动

**首次使用 / 新机器**：双击 `仅第一次启动用-环境检查与依赖安装.bat`，脚本会自动：

1. 检查 Python 3 与 Node.js（缺失时提示安装）
2. 配置国内镜像（pip 清华源、npm 淘宝源）
3. 创建 `.venv`、安装后端依赖
4. 安装前端依赖并构建
5. 启动服务并打开 `http://localhost:8020`

**日常启动**：双击 `排班管理系统.bat`，脚本会自动：

1. 清理 8020 端口占用
2. 检查/创建 `.venv` 并安装后端依赖
3. 检查数据库（`data/schedule.db` 已随仓库提供）
4. 安装前端依赖并构建
5. 启动服务并打开 `http://localhost:8020`

> 说明：bat 脚本提示信息使用英文（纯 ASCII），以避免中文 Windows 控制台编码导致的乱码。

## 功能使用方式

### 一、排班管理（首页）

#### 1. 员工管理

- **搜索**：输入员工姓名或**拼音首字母**（如"张三"输 `zs`）即可实时过滤
- **组别筛选**：表头"组别"下拉选择，只看某个组
- **排序**：点击"班次类型"或"上班时间"列头切换升/降序
- **添加/编辑员工**：右上角设置菜单 → 添加员工；每行可编辑/删除
  - 班次类型分**轮换班次**和**固定班次**；固定班次需选择固定上班时间（8:00~13:00）
- **组别管理**：设置菜单 → 编辑组别，可添加组别、删除组别（删除后组内员工自动归入"待分配"，员工不会被删除）

#### 2. 规则配置

左侧选择组别，右侧配置该组的轮换规则，**每类配置需单独点"保存配置"**；左侧总览会实时展示当前配置摘要。

**多人轮换**

- 模式切换：**标准轮换** / **特殊轮换**
- 标准模式：优先策略（优先早班/优先晚班）、早班时间与人数、晚班时间与人数、轮换起始日期
- 特殊模式：特殊时间（逗号分隔，如 `8:00, 10:00`，几段时间就每周挑几人）、其余员工默认时间
- 轮换顺序：左侧列表**拖动调整顺序**（数字越小越先轮换），右侧"待排序员工"点击姓名加入；点列表里的 × 可移回

**子组轮换**

- 添加子组：选两位成员、各自上班时间；每周两人互换时间
- 子组成员不全时排班会给出警告，不会强行排班

**单人轮换**

- 为个人配置两个时间点和起始周次（单周/双周），按周交替

#### 3. 排班生成

- 打开页面**默认自动生成下一周**（以周一为周起始）的排班
- 切换开始日期或勾选/取消组别，**自动重新生成**，无需点按钮
- 预览为"电脑部上班时间表"，按时间段分行展示员工
- 顶部按钮：
  - **保存快照**：保存当前排班（同周重复保存会覆盖）
  - **查询快照**：查看历史快照，可加载（恢复预览）或删除
  - **导出图片**：把预览表导出为 PNG
- 若某些员工未排上班、子组缺搭档、多人轮换人数不足，会在预览下方显示警告

### 二、值班管理（`/duty` 页面）

#### 1. 值班小组

- 添加小组：输入名称并可从员工列表搜索添加成员
- 每行可**编辑成员**（搜索添加/移除）、**重命名**、**删除**

#### 2. 值班配置

- 左侧选择小组，右侧配置：
  - **值班人数**：每组每周值班人数
  - **轮换起始日期**：必须是周日（日历只允许选周日）
  - **轮换顺序**：拖动排序，右侧待排序成员点击加入
- 保存配置后生效

#### 3. 值班表生成

- 打开页面**默认自动生成本周**（以周日为起始）的值班表
- 切换日期或勾选小组自动重新生成
- 值班表为 6 个岗位：制作、工艺、调图、布标、QC、机动（调图行内联显示机动岗）
- **轮休设置**：点击表格中轮休行的"日期类型"格，选择 周六/周一~周五轮休 或 空；点击轮休行的员工格，从本周值班员工中选择轮休人员
- 同样支持**保存快照、查询快照、导出图片**

### 三、AD 域同步（`/ad` 页面）

#### 1. 连接配置

- 服务器地址:端口（支持 `ldap://`、`ldaps://` 前缀，自动识别加密与默认端口 389/636）
- Base DN（如 `ou=技术部,dc=example,dc=com`）
- 用户名、密码：**每次操作都需输入，系统不保存凭证**

#### 2. 使用流程

1. **测试连接**：验证地址、账号、密码是否正确，显示可查询到的用户数
2. **预览差异**：拉取 AD 用户并与本地对比，自动分为四类：
   - 新增（AD 有、本地无）、变更（姓名/组别/工号有差异）
   - 已离职（本地有、AD 已无）、已忽略
   - 可对每条记录**勾选/取消**，也可点击"忽略"将其移入忽略列表
3. **确认导入**：按勾选结果导入——创建新员工、更新已有员工、自动创建缺失的组别
4. **同步日志**：查看最近一次导入的统计（新增/更新/建组数/AD 总数）
5. **忽略列表**：被忽略的用户不参与预览和导入，可随时取消忽略

### 四、通用功能

- **快照系统**：排班和值班共用一套快照，按周标识区分，同周覆盖保存
- **图片导出**：排班表/值班表均可一键导出 PNG
- **启动方式**：新机器用"仅第一次启动用"脚本准备环境，日常用"排班管理系统"脚本启动（见上）

## 手动部署

```bash
# 1. 克隆
git clone https://github.com/<你的账号>/shift-manager.git
cd shift-manager

# 2. 后端
py -3 -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
.venv\Scripts\python -m uvicorn backend.main:app --host 0.0.0.0 --port 8020

# 3. 前端构建（首次必须；之后仅在源码变更后需要）
cd frontend
npm install
npm run build
cd ..
```

启动后访问 `http://localhost:8020`（生产模式由 FastAPI 直接托管前端构建产物）。

## 开发模式

```bash
# 终端 1：后端（热重载）
.venv\Scripts\python -m uvicorn backend.main:app --port 8020 --reload

# 终端 2：前端 Vite（http://localhost:5173，/api 自动代理到 8020）
cd frontend
npm run dev
```

## 数据库

- `data/schedule.db` 随仓库提交，克隆后直接可用
- `-wal` / `-shm` 临时文件不入库（已在 `.gitignore` 中忽略）
- 多人/多机协作时：每次部署前先 `git pull` 获取最新数据库；多台机器同时写入数据会产生合并冲突，建议单一机器维护数据或做好备份

## 测试

```bash
.venv\Scripts\python -m unittest backend.tests.test_ad_routes
```

## 端口说明

服务默认端口为 **8020**（启动脚本、后端 CORS、前端开发代理均以此为准）。
如需改端口，需同步修改三处：

- `排班管理系统.bat`
- `backend/main.py`（CORS 允许来源）
- `frontend/vite.config.ts`（开发代理）

## 注意事项

- 当前版本尚未实现管理员认证，写操作（增删员工、修改规则、AD 同步等）对内网所有可访问者开放，部署时请注意网络访问控制
- AD 连接凭证不会持久化，每次操作需重新输入；数据库 `system_config` 中请勿存入明文密码
